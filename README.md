# Nib’s Little Kitchen — support and privacy

Public, static legal/support pages only. The game and its assets are not hosted in this repository.

- `index.html`: support/privacy directory
- `support.html`: parent help and restoration instructions
- `privacy.html`: published privacy policy

GitHub Pages publishes the root of `main`. No application JavaScript, tracking scripts, remote fonts, forms, billing SDKs or gameplay runtime are included. GitHub hosting handles visitor requests under its own policies; see the policy page.

The privacy page is exported from the app’s structured privacy-policy source. Future policy edits should keep that source and these public disclosures consistent.
